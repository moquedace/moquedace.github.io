# moquedace.github.io

Personal academic site of **Cássio Marques Moquedace** — soil scientist and postdoctoral researcher at ESALQ-USP.

🔗 **[moquedace.github.io](https://moquedace.github.io)**

---

## About

Static site built with plain HTML/CSS/JS. No frameworks, no build step — just a single `index.html` deployed via GitHub Pages.

### Sections

| # | Section | Content |
|---|---------|---------|
| 01 | Research Focus | Four core research lines, each linked to a representative paper |
| 02 | Selected Work | Three curated publications with DOI links |
| 03 | Visual Output | Cartographic outputs from published research (16:9 WebP) |
| 04 | Tools & Methods | Languages, platforms, ML/AI, spatial and discipline tags |
| 05 | Bio | Bilingual profile (EN / PT) |
| 06 | Contact | Email + academic profiles |

### Features

- **EN / PT language toggle** — full page switches between English and Portuguese; preference saved in `localStorage`
- **Responsive** — single-column layout on mobile
- **Active nav** — section highlighting via `IntersectionObserver`
- **WebP assets** — all images converted and optimised (60–96 % size reduction)
- MIT licensed, open to reuse
